CorpoRite Settings

Convert Hinglish to professional corporate English on any website.

OpenAI API

CorpoRite uses OpenAI to rewrite text. Your key is stored in Chrome sync storage and sent only to api.openai.com.

Writing style

Keep original tone

When on, rewrites keep your personality and warmth instead of forcing neutral corporate voice.

Allowed websites

Only run on selected websites

When on, CorpoRite works only on URLs you list below. When off, it runs on all sites.

Use a domain (web.whatsapp.com), partial host (linkedin), or full URL prefix (https://mail.google.com).

Auto-suggest while typing

When off, press Alt+Shift+C to open suggestions (saves API tokens).

How long to wait after you stop typing before requesting a suggestion.

Privacy policy

How to use

  1. Open a website (WhatsApp Web, Gmail, LinkedIn, etc.) and click a text field.
  2. Press Alt+Shift+C for suggestions (or enable auto-suggest while typing).
  3. Click Accept or press Ctrl+Enter to replace your text.
  4. Select text first to rewrite only the selection.

Customize the shortcut at chrome://extensions/shortcuts.
