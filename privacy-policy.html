CorpoRite Privacy Policy

Last updated: June 2026

Overview

CorpoRite is a Chrome extension that helps you rewrite Hinglish or informal Indian English into professional corporate English while you type in web text fields. This policy explains what information the extension accesses, how it is used, and what is shared with third parties.

CorpoRite is designed to run only when you request a suggestion (for example, by pressing Alt+Shift+C or enabling optional auto-suggest). We do not operate our own servers for text rewriting.

Information we access

CorpoRite may access the following information:

  • Text you type in supported input fields (input, textarea, and contenteditable) when you request a rewrite or when auto-suggest is enabled.
  • Your extension settings, such as formality level, tone preference, auto-suggest toggle, and your OpenAI API key.
  • Selected text, if you highlight a portion of text before requesting a suggestion.

CorpoRite does not read password or email input fields. It does not collect your browsing history, page URLs for analytics, or unrelated page content outside the active text field context.

How your information is used

  • To generate rewrite suggestions using AI.
  • To replace text in the field when you click Accept.
  • To copy the accepted suggestion to your clipboard when you accept a result.
  • To save your preferences and API key locally in Chrome storage.

Your data is used solely to provide the extension’s core functionality. We do not use your data for advertising, profiling, or selling to third parties.

Where data is stored

  • Chrome sync storage — your settings and OpenAI API key are stored in your Chrome profile via chrome.storage.sync. This keeps your preferences available across devices signed into the same Chrome account.
  • On your device only — suggestion panels and UI are rendered locally in the page. Accepted text is written directly into the field you are editing.

Third-party services

When you request a suggestion, the text to be rewritten is sent to OpenAI at https://api.openai.com using your own API key that you enter in CorpoRite settings.

  • CorpoRite does not provide or host the AI service.
  • OpenAI processes the text according to its own terms and privacy policy.
  • You are responsible for your OpenAI account, API usage, and any charges incurred.

OpenAI privacy policy: openai.com/policies/privacy-policy

Permissions explained

  • storage — saves your settings and API key in Chrome.
  • Host access to api.openai.com — allows the extension to send rewrite requests to OpenAI when you trigger a suggestion.
  • Content scripts on web pages — detects text fields and shows the suggestion panel where you type (e.g. Gmail, WhatsApp Web, LinkedIn). Scripts run only to support in-page rewriting when you use the extension.

Remote code

CorpoRite does not download or execute remote JavaScript at runtime. All extension code is bundled in the published package. Network requests to OpenAI return text suggestions only; those responses are displayed in the UI or inserted as user-visible text. They are never executed as code.

Data sharing and sale

We do not sell, rent, or trade your personal information. The only third-party sharing occurs when you explicitly request a rewrite and your text is sent to OpenAI using your API key.

Security

Communication with OpenAI uses HTTPS. Your API key is stored in Chrome sync storage on your device and is transmitted only to api.openai.com when a rewrite is requested. You should keep your API key private and revoke it if you believe it has been compromised.

Children’s privacy

CorpoRite is not directed at children under 13, and we do not knowingly collect personal information from children.

Your choices

  • Disable the extension at any time from the CorpoRite toolbar popup.
  • Remove your OpenAI API key from settings.
  • Uninstall the extension to stop all data access.
  • Use manual shortcut mode (default) to avoid API calls while typing.

Changes to this policy

We may update this privacy policy from time to time. The “Last updated” date at the top of this page will reflect any changes. Continued use of CorpoRite after changes constitutes acceptance of the updated policy.
